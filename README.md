I build Python tools that make data and model behavior easier to inspect. My current focus is temporal evaluation, reproducibility, and document workflows that keep source evidence visible.

## Selected projects

### [RiskReplay](https://github.com/ah682/riskreplay)
Reconstruct historical payment decisions using only evidence available at the time, compare policies, and inspect missing state and temporal leakage. Includes fitted scikit-learn models, chronological evaluation, and reproducible artifacts.

[Interactive demo](https://ah682.github.io/riskreplay/) · [Model evidence](https://ah682.github.io/riskreplay/?view=models) · [Evaluation protocol](https://github.com/ah682/riskreplay/blob/main/docs/EVALUATION.md) · [Build checks](https://github.com/ah682/riskreplay/actions)

The demo uses owned synthetic data. It demonstrates the evaluation workflow; real merchant effectiveness and production throughput remain unvalidated.

### [NoticeForge](https://github.com/ah682/noticeforge)
Review semiconductor change notices with source-linked parts, deadlines, exceptions, BOM matching, and JSON/XML exports. Runs locally with a rules baseline; optional model experiments retain their measured failures and costs.

[Project overview](https://ah682.github.io/noticeforge/) · [Walkthrough](https://github.com/ah682/noticeforge/blob/main/docs/WALKTHROUGH.md) · [Evaluation](https://github.com/ah682/noticeforge/blob/main/docs/EVALUATION.md) · [Build checks](https://github.com/ah682/noticeforge/actions)

Current extraction evidence comes from a small synthetic development corpus. Unfamiliar supplier documents and engineer usability still need independent evaluation.
